## Бренд / дизайн / ограничения
Спокойная инженерная надёжность, сдержанный old money, избегать клише и посредственности, минимализм без слепого шаблона; цветовые ориентиры #1A2A4A (тёмно-синий), #F7F4EF (тёплый светлый), #C4A35A / #C8A06A (умеренная бронза/латунь). Для старой концепции визитки использовались Lora Semibold + Golos Text, но решение о финальных шрифтах печати проверить по последнему файлу.
Не обещать: «весь дом», фиксированную автономность, обязательную работу котла/холодильника/интернета/насоса без расчёта, стабилизацию входного напряжения, моментальное переключение, пятилетнюю гарантию, монтаж в цене. Для видеорекламы действует отдельный запрет двух текстовых надписей.
Визитка: не страшилки и аварии, не вымышленные QR, не золотые рамки, не сложный жаргон. Телефон и 2 QR разборчивы; CMYK, запас 3 мм, реальный масштаб, тест сканирования и пробный лист.

## Важные незакрытые вопросы
1. Утверждённый конечный тираж и печать визиток не подтверждены.
2. Итоговый MP4 и работа QR внутри его последней версии не перепроверены.
3. Нет комплекта серийных шильдиков, заводских паспортов, инструкции/схемы подключения всех систем и подтверждённых условий локальной гарантии.
4. Для ДОМ 5 остаются проблемы эксплуатации: при входном ~170 В зарядка могла не происходить; при 0 В входа и ~230 В на выходе срабатывал автомат. Причины не диагностированы. Самостоятельные вмешательства в электрощит не рекомендовать.
5. Подача заявки через живой MAX, доступность сайта в ЛНР без VPN и своевременное обновление через service worker требуют испытаний на реальных устройствах.
6. Полный актуальный перечень местных рекламных каналов/групп Стаханова не завершён/не верифицирован.
7. Старые README и каталог от 05.11 содержат устаревшие цены — приоритет у кода main 18.11 и поздних коммерческих решений.
