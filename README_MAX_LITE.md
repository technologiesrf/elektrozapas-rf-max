## Что входит
- index.html — главная, товары, форма заявки и SVG-анимация (без внешних шрифтов или JS-фреймворков)
- styles.css и app.js — локальные стили и сценарии
- assets/*.webp — семь локальных изображений в формате WebP
- sw.js — необязательное кэширование оболочки после первого открытия по HTTPS

В предыдущем прототипе отдельный HTML-файл весил около 150 КБ, а полный архив с иллюстрациями и видео — несколько мегабайт. Облегчённая версия поставляется без необязательного видео; оно осталось в прежнем проекте. Эта версия разделена на компоненты: сначала загружаются разметка/стили/код, затем фотографии только при необходимости. Главная анимация — SVG/CSS без GIF или видео. Нет внешних CDN, трекеров, шрифтов и аналитики.

## Публикация
1. Чат-бот «Электрозапас РФ» уже создан, статус «На модерации». Не создавайте второй бот; дождитесь одобрения для доступа к его настройкам.
2. Загрузите содержимое этой папки на доступный из ЛНР HTTPS-хостинг в РФ, сохраняя относительные пути. Например, Yandex Object Storage (Static website) или VK Cloud. `index.html` — начальная страница. Не загружайте ZIP без распаковки.
3. Получите URL вида `https://ваш-домен.ru/` (домен должен быть работоспособен в РФ; https-сертификат действующий).
4. Откройте URL на Android и iPhone внутри MAX из ЛНР без VPN, на мобильном интернете; убедитесь, что 7 фотографий и форма работают. Проверьте в режиме нестабильной сети и после повторного открытия.
5. В настройках одобренного бота (Чат-боты → бот → ⋮ → Настройки) укажите URL приложения и кнопку «Открыть».
6. Протестируйте через кнопку в чате MAX, а не только в обычном браузере.

## Важно
* Текущий код не отправляет заявки в MAX автоматически: он только копирует подготовленное обращение. Нельзя объявлять приём заявок готовым до подключения серверного обработчика и тестирования. Токен бота хранить только на сервере, никогда не в HTML/JS.
* При обращении из MAX обязательно валидировать initData на сервере по официальной инструкции: https://dev.max.ru/docs/webapps/validation .
* Публикация на российском облаке не гарантирует доступности у всех операторов ЛНР. Это необходимо проверить на реальной SIM без VPN.
* Для дальнейших обновлений сервис-воркера меняйте версию константы CACHE в sw.js; при проблемах с кэшем очистите данные сайта и перезагрузите.
* На слабой сети первый запуск всё равно требует доступа к хостингу; после первого открытия оболочка может открываться из кэша, если MAX WebView разрешает service worker.
* Стоимость монтажа отдельно. Проверяйте инженерную совместимость и автопереключение перед продажей.

Исходную v7 и предыдущие файлы не меняли.
